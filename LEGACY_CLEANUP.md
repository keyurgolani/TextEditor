# Legacy Files Cleanup

## Files That Can Be Removed

The following legacy files from the Ant/NetBeans build system are no longer needed:

### NetBeans Configuration
- `nbproject/` directory (entire folder)
  - `build-impl.xml`
  - `project.properties`
  - `project.xml`
  - `genfiles.properties`
  - `private/` subdirectory

### Ant Build Files
- `build.xml` - Ant build configuration
- `manifest.mf` - Old manifest file (now generated by Maven)

### Build Output (Legacy)
- `build/` directory - Old Ant build output
- `dist/` directory - Old distribution output

## Files That Should Be Kept

### Source Code
- `src/texteditordemo/*.java` - All Java source files (modernized)

### Modern Build System
- `pom.xml` - Maven configuration
- `build.sh` - Alternative build script

### Documentation
- `README.md` - Project documentation
- `MIGRATION_GUIDE.md` - Migration details
- `QUICKSTART.md` - Quick start guide
- `LEGACY_CLEANUP.md` - This file

### Configuration
- `.gitignore` - Version control ignores

## Cleanup Commands

To remove all legacy files:

```bash
# Remove NetBeans configuration
rm -rf nbproject/

# Remove Ant build files
rm build.xml manifest.mf

# Remove old build outputs
rm -rf build/ dist/

# Optional: Remove backup Java file if it exists
rm src/texteditordemo/TextEditor_old.java 2>/dev/null || true
```

## One-Line Cleanup

```bash
cd /projects/sandbox/TextEditor && rm -rf nbproject/ build/ dist/ build.xml manifest.mf && echo "Legacy files cleaned up!"
```

## Why Keep build.xml and manifest.mf?

For reference purposes, you may choose to keep these files temporarily:
- They document the original build configuration
- They can help if you need to understand legacy settings
- They're small and don't interfere with modern builds

However, they are not needed for building or running the application.
